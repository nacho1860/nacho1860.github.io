2. Purpose

Personal Playlist Manager is a private, non-commercial local application used solely to organize videos from YouTube channels subscribed to by its sole user into the user's own YouTube playlists.

3. Data processed

The application may process YouTube channel IDs and titles, playlist IDs and titles, video IDs, and information required to determine playlist membership. Authentication uses Google OAuth 2.0. OAuth credentials are stored locally on the user's computer.

4. YouTube API

The application uses the YouTube Data API and operates under the applicable YouTube API Services Terms of Service and Google API Services User Data Policy.

  • YouTube API Services Terms of Service
  • Google Privacy Policy

5. Sharing

The application is not a public service and does not sell or provide the processed data to third parties. Communication with Google/YouTube occurs only as required for the API and OAuth functions.

6. Local storage

Configuration and progress data are stored locally on the operator's computer. The application does not store the user's Google password.

7. Deletion and revocation

Local application data can be deleted from the computer at any time. OAuth access can be revoked through Google account settings.
